- **Recall:** 
	1. Suppose $X_{i} \sim N(\mu_{i}, \sigma_{i}^2);\ i=1,\dots,n$ and $X_{1},\dots X_{n}$ are all independent.
		- Suppose $a_{1}\dots a_{u}$ are constant.
			- Set $T = \sum_{i=1}^{n} a_{i} X_{i}$ Then $\mathbb{E}(T) = \sum_{i=1}^{u} a_{i} \mu_{i}$
			- $\operatorname{Var}( T ) = \sum_{i=1}^{n} a_{i}^2 \sigma_{i}^2$
				- **N.B.**: T is a normal random variable itself
			- So $T \sim N\left( \sum_{i=1}^n a_{i}\mu_{i},\ \sum_{i=1}^n a_{i}^2 \sigma_{i}^2 \right)$
	
	2. $\underbrace{ X_{1}\dots X_{n} }_{ \text{random sample} } \overset{\text{iid}}{\sim} N(\mu, \sigma^{2})$
		- Sample mean: $\overline{ X } = \dfrac{X_{1} + \cdots + X_{n}}{n}$
			- $\mathbb{E}(\overline{ X }) = \mu; \ \operatorname{Var}( \overline{ X } ) = \dfrac{\sigma^{2}}{n}$
		- $\overline{ X } \sim N(\mu, \dfrac{\sigma^{2}}{n})$
	
- Standardization of $\overline{ X }$
	- $Z = \dfrac{\overline{ X } - \mu}{\sigma /\sqrt{ n }} \sim N(0,1)$
		- still going to be normal because it's the linear combination of $\overline{ X }$
		- show the expectation of $Z$ is $0$
		- expectation of $Z$ is the same as
			- $\mathbb{E}(Z) = \mathbb{E}\left( \dfrac{\overline{ X }-\mu}{\sigma /\sqrt{ n }} \right) = \mathbb{E}\left( \dfrac{1}{\sigma /\sqrt{ n }} (\overline{ X } - \mu) \right) = \dfrac{1}{\sigma / \sqrt{ n }} \left[ \mathbb{E}(\overline{ X } - \mu) \right] = \dfrac{1}{\sigma /\sqrt{ n }}\left( \underbrace{ \mathbb{E}(\overline{ X }) }_{ \mu }- \underbrace{ \mathbb{E}(\mu) }_{ \mu } \right) = 0$
	- $\operatorname{Var}( Z ) = \operatorname{Var}\left(  \dfrac{1}{\sigma /\sqrt{ n }}(\overline{ X } - \mu)  \right)$
		- $= \left( \dfrac{1}{\sigma /\sqrt{ n }} \right)^2 \operatorname{Var}( \overline{ X }-\mu )$
		- $= \dfrac{1}{\sigma^{2} /n} \operatorname{Var}( \overline{ X } )$
		- $= \dfrac{1}{\sigma^{2} / n} \cdot \dfrac{\sigma^{2}}{n} = 1$
		- **N.B.**: should be able to prove it step by step like this on the test

- **Example.** $X$ and $Y$ are independent and normal.
	- $X \sim N(2,4);\ Y\sim N(3,9)$
	1. Find $P(X > Y)$
		- see if you can move all the variables to one side so it's a linear combination of the random variables so that we know it's normal
		- $= P(X - Y > 0)$
			- now we know that $X-Y$ is a linear combination, we know it's normal so we have to find the mean and variance
		- $\mathbb{E}(X-Y) = \mathbb{E}(X) - \mathbb{E}(Y) = 2 - 3 = -1$
		- $\operatorname{Var}( X-Y ) = \operatorname{Var}( X ) + \operatorname{Var}( Y ) = 4 + 9 = 13$
			- recall you can foil from covariance
			- **N.B.**: don't forget it's a plus (review for final)
		- So we can say $X-Y \sim N(-1, 13)$
			- **N.B.**: think of $X-Y$ as $T$
		- Thus, $P(X-Y > 0) = P\left( \dfrac{(X-Y)-(-1)}{\sqrt{ 13 }} > \dfrac{0 - (-1)}{\sqrt{ 13 }} \right) = P(Z > \dfrac{1}{\sqrt{ 13 }})$
			- $= 1 - P\left( Z \leq \dfrac{1}{\sqrt{ 13 }} \right) = 1 - \Phi\left( \dfrac{1}{\sqrt{ 13 }} \right)$
			- proceed by plugging it into the calculator and then looking it up on the z-table

### Central Limit Theorem (CLT)

- What the theorem says..
	- Suppose $X_{1}\dots X_{n}$ are iid random variables from an _arbitrary_ distribution that has mean $\mu$ and variance $\sigma^{2} < \infty$.
	- Then the quantity $Z = \dfrac{\overline{ X }-\mu}{\sigma /\sqrt{ n }}$ converges in distribution to the standard normal $N(0,1).$
	- We write $\dfrac{\overline{ X }-\mu}{\sigma / \sqrt{ n }} \overset{\text{D}}{\longrightarrow} N(0,1)$ as $n$ goes to infinity.
		- **N.B.**: $\overset{ D }{\longrightarrow}$ means it converges to the normal distribution
	- **N.B.**: in other words...
		- If $N$ is large enough, then we can approximate the distribution as above.
		- the sample mean is roughly normal as $n$ goes to infinity
- Meaning of the CLT:
	1. For large $n$ we can assume that $\dfrac{\sqrt{ n } (\overline{ X }-\mu)}{\sigma}$ is approximately normal with mean $0$ and variance $1$.
	2. $\boxed{ \dfrac{\sqrt{ n }(\overline{ X } - \mu)}{\sigma} \sim N(0,1) }$
		- de-standardizing here..
		- $\overline{ X } - \mu \sim N\left( 0, \dfrac{\sigma^{2}}{n} \right)$
		- $\overline{ X } \sim N\left( \mu, \dfrac{\sigma^{2}}{n} \right)$
		- $\dfrac{X_{1}+\cdots+X_{n}}{n} \sim N\left( \mu, \dfrac{\sigma^{2}}{n} \right)$
		- $\boxed{ X_{1} + \cdots + X_{n} \sim N(n\mu, n\sigma^{2}) }$
			- sum of random variables has approximately $n\mu$ and $n\sigma^{2}$
- **N.B.**: If $n > 50,$ then can use this theorem to approximate on exam

- **Example.** The weight of a brand of bolt is a random variable with mean $1\mathrm{g}$ and standard deviation $0.13\mathrm{g}$.
	- Suppose 100 of the bolts are selected at random.
	- Find the probability the sum of their weight is less than $102\mathrm{g}$? Use CLT.
	
	- our sample size is $n=100$
	- so we're looking for $P(X_{1} + X_{2} + \cdots + X_{100} < 102)$
		- where $X_{1} + \cdots + X_{100} \sim N(100(1), 100(0.13)^2)$
	- $\Rightarrow P\left( \dfrac{X_{1} + \cdots + X_{100}-100}{\sqrt{ 100 (0.13)^2 }} \leq \dfrac{102 - 100}{\sqrt{ 100 (0.13)^2 }} \right)$
		- $=P \left( Z < \dfrac{2}{10(0.13)} \right)$
		- $=P\left( Z < \dfrac{2}{1.3} \right)$
		- $=\Phi \left( \dfrac{2}{1.3} \right)$
