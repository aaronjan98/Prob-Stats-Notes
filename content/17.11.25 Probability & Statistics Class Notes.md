## Several Random Variables

1. Suppose $X_{1}\dots X_{n}$ are continuous type random variables. Their joint pdf $f(x_{1}\dots x_{n})$ satisfies the following properties.
	- **N.B.**: joint distribution, pdf should satisfy $n$ variables
	1. $f(x_{1}, \dots, x_{n}) \geq 0 \quad \forall x_{1},\dots, x_{n} \in \mathbb{R}.$
	2. $\int_{-\infty}^\infty \cdots \int_{-\infty}^\infty f(x_{1},\dots, x_{n})dx_{1}dx_{2}\cdots dx_{n} = 1$

2. The joint CDF of $x_{1}\cdots x_{n}$ is $F(x_{1},\dots,x_{n}) = P(X_{1} \leq x_{1}, \dots X_{n} \leq x_{n}) = \int_{-\infty}^{x_{n}}\cdots \int_{-\infty}^{x_{1}}f(t_{1},\dots,t_{n})dt_{1}\dots dt_{n}.$

3. Expectation for a function $\mu(X_{1},\cdots,X_{n}).$
	- $\mathbb{E}(\mu(X_{1},\dots, X_{n})) = \int_{-\infty}^\infty \cdots \int_{-\infty}^\infty \mu(x_{1},\dots,x_{n})f(x_{1},\dots,x_{n})dx_{1}\dots dx_{n}$

- **Remark.** If $X_{1}\dots X_{n}$ are discrete type random variables, the idea is the same with the continuous type. Just replace integrals with summation.

4. Marginal pdf of $X_{i}; \ i = 1 \cdots n.$
	- Do just for $X_{1}$ first (recall you integrate y out completely and integrate over all x)
		- $f_{X_{1}} (x_{1}) = \int_{-\infty}^\infty \cdots \int_{-\infty}^\infty f(x_{1}, \dots, x_{n})dx_{2} \dots dx_{n}$ where $x_{1} \in S_{X_{1}}$
	- **N.B.**: Do the other ones by yourself $X_{2}, X_{3},$ etc.

### Covariances

1. Suppose $X_{1}$ and $X_{2}$ are two random variables with means $\mu_{\scriptsize X_{1}}$ and $\mu_{\scriptsize X_{2}}$ and variance $\sigma_{\scriptsize X_{1}}^2$ and $\sigma_{\scriptsize X_{2}}^2$.
	- Now suppose $a_{1}$ and $a_{2}$ are constants.
	- And $b_{1}$ and $b_{2}$ are also constant.
		
	1. Find the expectation, $\mathbb{E}(a_{1}x_{1} + a_{2}x_{2}+ b_{1})$
		- should always ask if two random variables are independent (if not specified, don't treat them as such)
		- expectation is linear operator that is all the 
			- move expectation inside of all random variables
		- Answer. $\mathbb{E}(a_{1}x_{1} + a_{2}x_{2} + b_{1}) = a_{1}\mathbb{E}(X_{1}) + a_{2}\mathbb{E}(X_{2}) + \mathbb{E}(b_{1}) = \boxed{ a_{1}\mu_{\scriptsize X_{1}} + a_{2}\mu_{\scriptsize X_{2}} + b_{1} }$
	2. Find $\operatorname{Cov}(a_{1}x_{1} + a_{2}x_{2}, \ b_{1}x_{1} + b_{2}x_{2})$
		- $\operatorname{Cov}(a_{1}x_{1} + a_{2}x_{2},\ b_{1}x_{1} + b_{2}x_{2})$
			- **Foiling Technique**:
				- if we were to foil for example $(a_{1}x_{1} + a_{2}x_{2})(b_{1}x_{1} + b_{2}x_{2})$
				- $= a_{1}b_{1}x_{1}x_{1} + a_{1}b_{2}x_{1}x_{2} + a_{2}b_{1}x_{2}x_{1} + a_{2}b_{2}x_{2}x_{2}$
		- you do the same thing with variance, but instead you group the constants together and put covariance for the random variables (where they meet)
			- $= a_{1}b_{1} \operatorname{Cov}(x_{1},x_{1}) + a_{1}b_{2}\operatorname{Cov}(x_{1},x_{2}) + a_{2}b_{1}\operatorname{Cov}(x_{2},x_{1}) + a_{2}b_{2}\operatorname{Cov}(x_{2},x_{2})$
			- **N.B.**: covariance of itself is just variance
				- also recall parameters of cov are symmetric
			- $= a_{1}b_{1}\operatorname{Var}( X_{1} ) + (a_{1}b_{2} + a_{2}b_{1})\operatorname{Cov}(x_{1},x_{2}) + a_{2}b_{2}\operatorname{Var}( X_{2} )$
			- $=a_{1}b_{1}\sigma_{\scriptsize X_{1}}^2 + a_{2}b_{2}\sigma_{\scriptsize X_{2}}^2 + (a_{1}b_{2} + a_{2}b_{1})\operatorname{Cov}(x_{1},x_{2})$
				- **N.B.**: just foil if you don't remember this is the output of variance
	3. Find $\operatorname{Var}( a_{1}x_{1} + a_{2}x_{2} + b_{1} )$
		- recall $\operatorname{Var}( aX+b ) = a^2\operatorname{Var}( X )$
			- so the constant doesn't matter, but you could still foil with the constant if you wanted
			- recall, $\operatorname{Var}( X ) = \operatorname{Cov}(X,X)$
				- that is, think about what's inside $\operatorname{Var}( a_{1}x_{1} + a_{2}x_{2} + b_{1} )$ as a big $X$ like this $\operatorname{Var}( \underbrace{ a_{1}x_{1} + a_{2}x_{2} + b_{1}  }_{ X })$
		- $= \operatorname{Var}( \underbrace{ a_{1}x_{1} + a_{2}x_{2} }_{ Y } )$
		- $= \operatorname{Cov}(a_{1}x_{1} + a_{2}x_{2},\ a_{1}x_{1} + a_{2}x_{2})$
			- now foil it
		- $= a_{1}^2 \underbrace{ \operatorname{Cov}(x_{1},x_{1}) }_{ \operatorname{Var}( X_{1} ) } + a_{1}a_{2}\operatorname{Cov}(x_{1},x_{2})+a_{2}a_{1}\operatorname{Cov}(X_{2}, X_{1}) + a_{2}^2\underbrace{ \operatorname{Cov}(X_{2},X_{2}) }_{ \operatorname{Var}( X_{2} ) }$
		- $=a_{1}^2 \operatorname{Var}( X_{1} ) + a_{2}^2\operatorname{Var}( X_{2} ) + 2a_{1}a_{2}\operatorname{Cov}(X_{1},X_{2})$
		- **N.B.**: variance is also covariance
			- if you don't know how to take variance, turn it into covariance to see the result
	
- Now, let's see a more general version of this beyond two random variables
- Suppose $X_{1}\cdots X_{n}$ are random variables with means (expectations)
	- $\mu_{1} \dots \mu_{n}$ and variances $\sigma_{1}^2 \dots \sigma_{n}^2$ respectively (each $X_{n}$ pairs with $\mu_{n}$)
- Suppose $a_{1}\dots a_{n}$ and $b_{1} \dots b_{n}$ are all constant.
	- Set $T = \sum_{i=1}^{n} a_{i}X_{i}; \quad W = \sum_{j=1}^{n} b_{j}X_{j}$
1. Find $\operatorname{Cov}(T, W)$
	- first, we need to replace $T$ and $W$ with their expressions
		- $\operatorname{Cov}(T,W) = \operatorname{Cov}\left( \sum_{i=1}^{n} a_{i}X_{i};\ \sum_{j=1}^{n}b_{j}X_{j} \right)$
		- $=\operatorname{Cov}(a_{1}x_{1}+\cdots + a_{n}x_{n}, b_{1}x_{1} + \cdots + b_{n}X_{n})$
			- foiling this would be the same as with the two random variables, but because there are $n$ of them, it will look like this...
		- $a_{1}b_{1}\operatorname{Cov}(x_{1},x_{2})+\cdots+ a_{1}b_{2}\operatorname{Cov}(x_{1},x_{n})$
			- $\Rightarrow \boxed{ \sum_{j} \sum_{i} a_{i} b_{j} \operatorname{Cov}(X_{i}, X_{j}) }$
			- can simplify a little when $i=j$
			- $= \sum_{i=1}^{n} a_{i}b_{i}\operatorname{Var}( X_{i} ) + \sum_{i\neq j} a_{i}b_{j}\operatorname{Cov}(X_{i}, X_{j})$
				- can even simplify further since covariance of $X_{i}$ and $X_{j}$ are the same?
2. Find $\operatorname{Var}( T ); \ \operatorname{Var}( W ).$
	- $\operatorname{Var}( T ) = \operatorname{Var}\left(  \sum_{i=1}^{n} a_{i} X_{i} \right)$
		- $= \operatorname{Cov}\left( \sum_{i=1}^{n} a_{i}X_{i},\ \sum_{i=1}^{n}a_{i}X_{i} \right)$
		- $= \operatorname{Cov}(a_{1}x_{1}+\cdots+a_{n}x_{n},\ a_{1}x_{1} + \cdots + a_{n}x_{n})$
			- same thing as $\operatorname{Cov}\left( \sum_{i=1}^{n} a_{i}X_{i},\ \sum_{j=1}^{n}a_{j}X_{j} \right)$
		- $= \sum_{i=1}^n a_{i}^2\operatorname{Var}( X_{i} ) + \sum_{i\neq j}a_{i}a_{j}\operatorname{Cov}(X_{i}, X_{j})$
			- can optionally write it as $\sum_{i=1}^{n} a_{i}^2\operatorname{Var}( X_{i} ) + 2\sum_{i < j} a_{i}a_{j}\operatorname{Cov}(X_{i}, X_{j})$
	- $\operatorname{Var}( W ) = \operatorname{Var}\left(  \sum_{j=1}^{n} b_{j}X_{j}  \right)$
		- $= \sum_{j=1}^{n} b_{j}s^2 \operatorname{Var}( X_{i} ) + \sum_{i \neq j} b_{i}b_{j}\operatorname{Cov}(X_{i}, X_{j})$
		- $= \sum_{j=1}^{n} b_{j}^2 \operatorname{Var}( X_{i} ) + 2 \sum_{i < j} b_{i}b_{j}\operatorname{Cov}(X_{i}, X_{j})$
		- **N.B.**: if the random variables were independent then we would just be left with $\sum_{j=1}^{n} b_{j}^2 \operatorname{Var}( X_{i} )$ because covariance of two random variables is $0$.
3. Find $\mathbb{E}(T)$ and $\mathbb{E}(W)$
	1. $\mathbb{E}(T) = \mathbb{E}\left( \sum_{i=1}^{n}a_{i}X_{i} \right) = \sum_{i=1}^n a_{i}\mu_{i}$
	2. $\mathbb{E}(W) = \mathbb{E}\left( \sum_{i=1}^n b_{j}X_{i} \right) = \sum_{i=1}^n b_{j}\mu_{j}$

- **Example.** $X$ and $Y$ are random variables with means $\mu_{\scriptsize X} = 2,\ \mu_{\scriptsize Y} = 7$ and $\sigma_{\scriptsize X}^2 = 19,\ \sigma_{\scriptsize Y}^2 = 15,\ \operatorname{Cov}(X, Y) = -2.$
- Find
	1. $\mathbb{E}(X+Y)$
		- similar to linear combinations of random variables
		- coefficients of $X$ and $Y$ is $1$ so $a_{1}, a_{2}$ is in there
		- $= \mu_{\scriptsize X} + \mu_{\scriptsize Y} = 2 + 7 = 9.$
	2. $\operatorname{Var}( X+Y )$
		- $= \operatorname{Var}( X ) + 2\operatorname{Cov}(X, Y) + \operatorname{Var}( Y ) = \sigma_{\scriptsize X}^2 + \sigma_{\scriptsize Y}^2 + 2\operatorname{Cov}(X,Y) = 19 + 15 + 2 (2)$
	3. $\mathbb{E}(X-Y)$
		- $=\mu_{\scriptsize X} - \mu_{\scriptsize Y} = 2 -7 = -5$
	4. $\operatorname{Var}( X-Y )$
		- $= \operatorname{Var}( X ) - 2\operatorname{Cov}(X,Y) + \operatorname{Var}( Y )$
			- **N.B.**: coefficient of $X$ and $Y$ have to be squared so only foiled together produced a negative?
		- $= \sigma_{\scriptsize X}^2 + \sigma_{\scriptsize Y}^2 - 2\operatorname{Cov}(X,Y) = 19 + 15 - 2(2)$
	5. $\operatorname{Cov}(X+Y,\ X-Y) = \operatorname{Cov}(X,X) - \operatorname{Cov}(X,Y) + \operatorname{Cov}(Y,X) - \operatorname{Cov}(Y,Y)$
		- $=\operatorname{Var}( X )-\operatorname{Var}( Y )$
		- $= \sigma_{\scriptsize X}^2 - \sigma_{\scriptsize Y}^2 = 19-15 = 4$

### Independence

- Random variables $X_{1} \dots X_{n}$ are independent if and only if their joint pdf can be written as:
	- $f(x_{1},\dots,x_{n}) = f_{1}(x_{1})f_{2}(x_{2})\cdots f_{n}(x_{n}) = \prod_{i=1}^n f_{i}(x_{I}) \quad \text{for all } x_{1}\dots x_{n} \in \mathbb{R}.$
	- where $f_{1} \cdots f_{n}$ are the marginal pdf of $X_{1}\dots X_{n}$ respectively
	- **N.B.**: if joint can be written as the product of $X_{1}\dots X_{n}$, then they're independent

- Suppose $X_{1}\dots X_{n}$ are independent:
	- Set $\mu_{1}(X_{1}),\dots, \mu_{n}(X_{n})$ function of $X_{1}\dots X_{n}$ respectively.
	- Then $\mathbb{E}\left( \mu_{1}(X_{1})\cdot \mu_{2}(X_{2}) \cdots\mu_{n}(X_{n}) \right) = \mathbb{E}(\mu_{1}(X_{1})) \mathbb{E}(\mu_{2}(X_{2}))\cdots \mathbb{E}(\mu_{n}(X_{n}))$
- Recall for any two random variables $X$ and $Y$: $\operatorname{Cov}(X,Y) = \mathbb{E}(XY) - \mathbb{E}(X)\mathbb{E}(Y)$
	- If $X$ and $Y$ are independent then: $\mathbb{E}(XY) = \mathbb{E}(X) \cdot \mathbb{E}(Y)$
	- That is, if $X$ and $Y$ are independent, then $\operatorname{Cov}(XY) = 0.$
