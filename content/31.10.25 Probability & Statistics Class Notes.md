## Standard normal distribution

- $Z \sim \operatorname{N}(0, 1);\ \mu= 0, \sigma^{2} = 1$
- pdf: $f_{Z}(x) = \dfrac{1}{\sqrt{ 2\pi }}e^{-\frac{1}{2}x^2}\ -\infty < x < \infty$
- CDF: $\Phi(x) = \int_{-\infty}^\infty \dfrac{1}{\sqrt{ 2\pi }}e^{-\frac{1}{2}t^2}dt; \ t \in \mathbb{R}$
	- $\Phi(x)$ is the shaded area under the curve $(-\infty, x)$
	- see table because integral is difficult to compute [^1]
		- can also use $p$ norm

- **Example:**
	1. Find $\mathbb{P}(Z < 2.5)$
		- **N.B.**: $<$ or $\leq$ doesn't matter
		- $\Phi(2.5)$ talks about the area from $-\infty \text{ to } 2.5$
		- look at the table and choose `0.9938` from column 0
	2. Find $\mathbb{P}(-0.6 < Z < 1.25)$
		- $= \Phi(1.25) - \Phi(-0.6) = 0.8944 - 0.2743$
			- get `0.8944` from column `0.05`
			- get `0.2743` from -0.6 (col 1)
				- or $\Phi(0.6) + \Phi(-0.6)$
				- $= \Phi(-0.6) = 1 - \Phi(0.6)$
				- $= 1 - 0.7257$
	3. Find $\mathbb{P}(|Z| < 2) = \mathbb{P}(-2 < z < 2)$
		- $\Phi(2) - \Phi(-2)$
		- can also write it as $2\Phi(2)-1$
			- $=\Phi(2) - (1-\Phi(2))$
			- $=2\Phi(2)-1$
			- $=2(0.9772) - 1 = 0.9545$ (within 2 standard deviations of the mean; use empirical rule to come up with answer on exam)
		- $\mathbb{P}(|Z| < 1) = 0.6827$ (within 1 standard devaition)
			- or could do $=2\Phi(1)-1$
	4. Find $\mathbb{P}(|Z| > 4.2)$
		- If we use the complement, we get $1 - \mathbb{P}(|Z| \leq 4.2)$
		- if we go to 4 standard deviations of the mean, then we can just round up the probability to 1 or 100\%
		- Answer: $1 -1 = \boxed{ 0 }$
	- another example of 4 standard deviation: $\mathbb{P}(Z < -3.9) =0$

#### Standardization

- Fact: $X \sim \operatorname{N}(\mu, \sigma^{2})\ \text{ iff } x = \mu + \sigma z \text{ where } Z \sim \operatorname{N}(0, 1)$.
	- it pushes the curve forward or backward depending on $\mu$ and depending on the $\sigma$, it'll make it narrower or wider
	- you can always get the expression $Z$ in there (bring normal to mean 0) if you know the mean and the standard deviation
- We standardize $Z$ to get $\mu$ as follows
	- get $Z$ only on the right side (solve for $Z$)
		- $X - \mu = \sigma Z$
		- $\boxed{ \dfrac{X - \mu}{\sigma} = Z }$
	- If $X \sim \operatorname{N}(\mu, \sigma^{2})$ iff
		- $Z = \dfrac{X-\mu}{\sigma} \sim \operatorname{N}(0,1)$

- Suppose $X \sim \operatorname{N}(\mu, \sigma^{2})$.
	- What is $\mathbb{P}(X \leq x)$?
		- in order to do this, we have the table for standard normal so we have to standardize the inequality
		- $= \mathbb{P}(X - \mu \leq x - \mu)$
		- then divide by $\sigma$
		- $= \mathbb{P}\left( \dfrac{X - \mu}{\sigma} \leq \dfrac{x - \mu}{\sigma} \right)$
		- $= \mathbb{P}(Z \leq \dfrac{x - \mu}{\sigma}) = \Phi\left(\dfrac{x-\mu}{\sigma}\right)$

- **Example.** The height of adult male is $\operatorname{N}(\mu=69, \sigma^{2} = 3^2)$
	- $X \sim \operatorname{N}(69, 3^2); \ \mu = 69,\ \sigma = 3.$
	1. Find the probability that the random selected person's height is $\mathbb{P}(X \leq 70)$.
		- the probability is the same as $\mathbb{P}\left(\dfrac{X-69}{3} \leq \dfrac{70-69}{3}\right) = \mathbb{P}(Z \leq 0.33) = \Phi(0.33) = 0.6293$
			- R-online: `pnorm(70, 69, 3)` = 0.6305587 [^2]
			- Find $0.6293$ from row `z=0.3` and col of `0.03` [^1]
	2. Find the probability that the random selected person's height is $\mathbb{P}(|X| < 74)$
		- Need to get rid of the absolute value sign
			- $= \mathbb{P}(-74 < X < 74)$
		- then we need to standardize
			- $\mathbb{P}\left( \dfrac{-74-69}{3} \leq \dfrac{X-69}{3} \leq \dfrac{74 - 69}{3} \right)$
			- $\mathbb{P}(-47.66 \leq Z \leq 1.67)$
			- $= \Phi(1.67) - \underbrace{ \Phi(-47.66) }_{ 0 } = \Phi(1.67) = 0.9525$
				- **N.B.**: get value from Z-row 1.6 and col 0.07 [^1]
			- R-online: `pnorm(1.67) - pnorm(-47.66)` = 0.9525403 [^2]
				- can also do it this way with absolute values `pnorm(74,69,3)-pnorm(-74,69,3)`
	3. Find the probability that the random selected person's height is $\mathbb{P}(|X-69| < 9)$
		- $=\mathbb{P}\left( -9 < X - 69 < 9 \right)$
			- the 69 is already subtracted for you
			- using empirical rule, we see it's within 3 standard deviation of the mean (can't be more than 9)
				- recall empirical rule says it should be $0.9973$
				- **N.B.**: Need to memorize the values for the empirical rule on Exams (won't be provided for you)
		- $=\mathbb{P}\left( \dfrac{-9}{3} < \dfrac{X - 69}{3} < \dfrac{9}{3} \right)$
			- $= \mathbb{P}(-3 < Z < 3) = 2 \Phi(3) - 1 = 2(0.9987) - 1 = 0.9974$
		- if for instance it was 57 instead of $69,$ then you would want to rearrange it yourself so that there is a 69 there
			- if the probability is $\mathbb{P}(\lvert X-32 \rvert < 9)$ for example
			- then it becomes $\mathbb{P}(-9 < X - 32 < 9)$
				- if confusing, add 32 to get $X$ there
			- otherwise you'd do: $\mathbb{P}\left( \dfrac{-9 + 32 - 69}{3} < \dfrac{X - 69}{3} < \dfrac{9+32 - 64}{3} \right)$
		- R-online: `pnorm(1)-pnorm(-1)` or with this way `pnorm(1,0,1)-pnorm(-1)` [^2]
			- input standard deviation (not $\sigma^{2}$)

### MGF of Normal Distribution

- Suppose $X \sim \operatorname{N}(\mu, \sigma^{2})$
1. MGF of $X$ is $M_{X}(t) = e^{\mu t + \frac{1}{2}\sigma^{2}t^2}$
	- **N.B.**: not doing proof, but would be fairly simple to do yourself
	- Example: $M_{X}(t) = e^{2t + \frac{1}{2}t^2}$
		- Specify the distribution of $X$?
			- $X \sim \operatorname{N}(2, 12)$
	- Remember:
		- If you take the derivative and plug in 0 you get expectation of $X$
		- and second derivative would be expectation of $X^2$

### Percentile of Normal Distribution

- Suppose $Z \sim \operatorname{N}(0, 1)$
	- For $0 < \alpha < 1;$ the $100(1-\alpha)$ percentile of $Z$ is denoted $Z_{\alpha}$ and is defined such that $$\int_{-\infty}^{Z_{\alpha}} \dfrac{1}{\sqrt{ 2\pi }}e^{-\frac{1}{2}t^2} dt = 1 -\alpha \;\text{ and }\; \int_{Z_{\alpha}}^\infty \dfrac{1}{\sqrt{ 2\pi }} e^{-\frac{1}{2}t^2}dt = \alpha$$
		- **N.B.**: [see pic of graph](https://photos.janovitch.com/share/B38F77HA3Fxj8A2BV6bjTb3ejOjdMRTd0B7gk9C8XQ_utYDFCSbGlP_s8Lf7KPFptVA)

- Suppose $X \sim \operatorname{N}(5, 6^{2})$
	- Find $c$ such that $\mathbb{P}(\lvert X-5 \rvert < c) = 0.9344$
		- easy way of doing it: work on equality inside to get just $Z$ 
		- $=\mathbb{P}\left(\left\lvert \dfrac{X-5}{6}\right\rvert < \dfrac{c}{6} \right) = 0.9544$
		- $=\mathbb{P}\left(\lvert Z \rvert < \dfrac{c}{6}\right)$
			- if we're within 2 standard deviation of the mean, then it implies by the empirical rule
			- $\dfrac{c}{6} = 2 \Rightarrow c = 12$
		- without empirical rule
			- $\mathbb{P}\left( \dfrac{c}{6} < Z < \dfrac{c}{6} \right) = 0.9544$
			- $\Phi\left( \dfrac{c}{6} \right) - \Phi\left( -\dfrac{c}{6} \right) = 0.9544$
			- $2 \Phi\left( \dfrac{c}{6} \right)-1 = 0.9544$
			- $\Phi\left( \dfrac{c}{6} \right) = \dfrac{1+0.9544}{2}$
			- $\dfrac{c}{6} = \Phi^{-1}\left( \dfrac{1+0.9544}{2} \right)$
			- $c = 6 \cdot \Phi^{-1}\left( \dfrac{1+0.9544}{2} \right)$
			- $c = 6 \cdot \Phi^{-1}(0.9772)$
				- $= 6 (2)$
