### Independence

- When random variables $X_{1}\dots X_{n}$ are independent
- Then the joint pdf/pmf $f(x_{1}\dots x_{n})$ can be written as:
	- $f(x_{1},\dots,x_{n}) = f_{1}(x_{1})\dots f_{n}(x_{n}) = \prod_{i=1}^n f_{i}(x_{i})$
		- **N.B.**: if we know random variables are independent then they can be written as the product of the marginals
	- for all $x_{1},\dots , x_{n} \in \mathbb{R}.$ where $f_{1}(x_{1}),\dots,f_{n}(x_{n})$ are the marginal pdf/pmfs of $x_{1}\dots x_{n}$

- Moreover if the random variables $X_{1}\dots X_{n}$ have the same marginal distribution then $f_{1} = f_{2} = \cdots = f_{n} = f$
	- **N.B.**: in the case that all the random variables (the marginals) have the same distribution, then...
	- The joint becomes $$
		f(x_{1},\dots, x_{n}) = f(x_{1}) \cdot f(x_{2})\cdots f(x_{n}) = \prod_{i=1}^n f(x_{i})
		$$
- Recapitulate: When $X_{1} \cdots X_{n}$ are independent and they all have the same distribution, we say $X_{1},\dots, X_{n}$ are independent and identically distributed.
	- We write $X_{1}\dots X_{n}$ are iid.
	- **N.B.**: $X_{1} \dots X_{n} \overset{\text{iid}}{\sim} f(x)$
		- the data underlying is called a random sample

- The sample/data underlying iid random variables $X_{1}\dots X_{n}$ is called a random sample of size $n$.
	- **N.B.**: getting into the realm of statistics because all that statistics is about is taking a sample so that you can make inferences about parameters you don't know

- **Fact.** about Independence
	- If $X_{1}\dots X_{n}$ are independent random variables. Then
	1. for $\mu_{1}(X_{1}), \mu_{2}(X_{2})\dots, \mu_{u}(X_{n})$ function of $X_{1}\dots X_{n}$
		- $\mathbb{E}(\mu_{1}(X_{1})\cdot \mu_{2}(X_{2})\dots \mu_{u}(X_{n})) = \mathbb{E}(\mu(X_{1})) \cdot \mathbb{E}(\mu_{2}(X_{2})\dots \mathbb{E}(\mu_{n}(X_{n})))$
		- $\mathbb{E}(X_{1} X_{2}) = \mathbb{E}(X_{1}) \cdot \mathbb{E}(X_{2})$
		- $\boxed{ \operatorname{Cov}(X_{i}, X_{j}) = 0; \quad i \neq j }$
			- any pair of random variables will give covariance of 0.

- **Example.** $X_{1}, X_{2}, X_{3}$ are iid random variables from the exponential distribution with pdf $f(x) = \begin{cases} e^{-x}, & x > 0 \\ 0 & \mathrm{elsewhere.} \end{cases}$
	- **N.B.**: iid and random sample mean the same thing
	1. Find the joint pdf of $X_{1}, X_{2}, X_{3}$
		- $f(x_{1}, x_{2}, x_{3}) = f_{1}(x_{1}) \cdot f_{2}(x_{2}) \cdot f_{3}(x_{3})$
		- but it's the same $f$ because they're iid, so
			- $= \begin{cases} e^{-x_{1}}e^{-x_{2}}e^{-x_{3}} & x_{1} > 0, x_{2} > 0, x_{3} > 0 \\ 0 & \mathrm{elsewhere} \end{cases}$
	2. Find $P(X_{1} < 2, 1 < X_{2} < 3, X_{3} > 9)$
		- $P(X_{1} < 2, 1 < X_{2} < 3, X_{3} > 9)$
			- this is really $P(A \cap B \cap C)$
			- $= P(X_{1} < 2)P(1 < X_{2} < 3)P(X_{3}>9)$
				- cdf of exponential computed at the given points
			- $=(1-e^{-2})(e^{-1}-e^{-3})(e^{-9})$
		- Alternative way to think about it
			- think $f(x)$ as just the marginal, so
			- $= P(X_{1} < 2)P(1 < X_{2} < 3)P(X_{3}>9)$
			- $= \left( \int_{0}^2 e^{-t}dt \right) \left( \int_{1}^3 e^{-t}dt \right) \left( \int_{9}^\infty e^{-t}dt \right)$
			- $= (1-e^{-2})(e^{-1}-e^{-3})(e^{-9})$
	3. Find $\operatorname{Cov}(X_{1}, X_{2}), \quad \operatorname{Cov}(X_{2}, X_{3})$

### Sample mean and variance of iid random variables

- Suppose $X_{1}\dots X_{n} \overset{\text{iid}}{\sim} f(x)$ with mean $\mu$ and variance $\sigma^{2}$
	- **N.B.**: every distribution has a mean and variance
		- all random variables come with same distribution which has the given mean and variance
	- iid means random sample, so the sample size is $n$
		- after we sample all these random variables, the sample mean $\overline{X}$
			- the mean of the random sample
	- The sample mean $\overline{ X } = \dfrac{X_{1} + X_{2} + \cdots + X_{n}}{n}$
		- $\overline{ X }$ is a random variable itself because it itself varies when sampling
			- what is the distribution of $\overline{X}$?
			- **N.B.**: as long as $n$ is large, it will be normal because of the central limit theorem
		- if you don't know the distribution, see if you can find its mean and variance

- What is $\mathbb{E}(\overline{X})$? $\operatorname{Var}( \overline{ X } )$?
	1. Is $\overline{X}$ a linear combination of $X_{1}\dots X_{n}$?
		- **N.B.**: a linear combination is just $X_{1}\dots X_{n} \Rightarrow a_{1}X_{1} + a_{2}X_{2}+\cdots + a_{n}X_{n}$
		- to match this form, we can write it as
		- $\overline{X} = \dfrac{X_{1} + \cdots + X_{n}}{n} = \dfrac{1}{n}\left( X_{1} + \cdots + X_{n} \right) = \dfrac{1}{n}X_{1} + \dfrac{1}{n}x_{2} + \cdots + \dfrac{1}{n}X_{n}$
			- see that $a_{1} = a_{2} = \cdots        = a_{n} = \dfrac{1}{n}$
			- $\overline{X}$ is linear combination of all the random variables
		- $\mathbb{E}(\overline{X}) = \mathbb{E}\left( \dfrac{1}{n}X_{1} + \dfrac{1}{n}X_{2} + \cdots + \dfrac{1}{n}X_{n} \right)$
			- recall the expectation of linear combination from last week
			- $= \dfrac{1}{n} \mathbb{E}(X_{1}) + \dfrac{1}{n}\mathbb{E}(X_{2}) + \cdots + \dfrac{1}{n}\mathbb{E}(X_{n})$
				- each trend variable has the same mean and the same variance because they're iid
			- $= \dfrac{1}{n}\mu + \dfrac{1}{n}\mu + \cdots + \dfrac{1}{n}\mu.$
		- $\mathbb{E}(\overline{X}) = \dfrac{1}{n}\bigg( \underbrace{ \mu+ \mu+ \cdots + \mu }_{ n } \bigg)$
			- $= \dfrac{1}{n} n \mu$
			- law of large number
				- $\overline{X}$ is called the unbiased estimate of $\mu$
				- very important result in statistics
			- $\boxed{ \mathbb{E}(\overline{X}) = \mu }$
	2. What's the variance of $\overline{X}$?
		- $\operatorname{Var}( \overline{X} ) = \operatorname{Var}\left(  \dfrac{1}{n} (X_{1} + \cdots + X_{n})  \right)$
			- **N.B.**: think of this as a constant multiplied by one big random variable
			- recall $\operatorname{Var}( aX ) = a^2\operatorname{Var}( X )$
		- $= \dfrac{1}{n^2} \operatorname{Var}( X_{1} + \cdots + X_{n} )$
			- this is a variance of a linear combination
			- recall $\sum a_{i}^2 \operatorname{Var}( X_{i} ) + \sum_{i \neq j} a_{i}-a_{j}\underbrace{ \operatorname{Cov}(X_{i}, X_{j}) }_{0}$
		- $= \dfrac{1}{n^2} \left[ \sum_{i=1}^n (1)^2 \sigma^{2} \right] = \dfrac{1}{n^2} \cdot n \cdot \sigma^{2} = \dfrac{\sigma^{2}}{n}$
		- $\boxed{ \operatorname{Var}( \overline{X} ) = \dfrac{\sigma^{2}}{n} }$
		- the expectation of the sample mean is the same that of the original distribution
		- the variance of the sample mean is smaller than that of the original distribution

#### Normal Distributions

- Suppose $X_{1} \dots X_{n}$ are independent and normally distributed with means $\mu_{1}\dots \mu_{n}$ and variances $\sigma_{1}^2\dots \sigma_{n}^2$
	- **N.B.**: not assuming iid, but assuming independence
	- Suppose $a_{1}\dots a_{n}$ are constant.
	- Set $T = \sum_{i=1}^n a_{i} X_{i}$
	
	1. $\mathbb{E}(T) = \sum_{i=1}^{n} a_{i}\mu_{i}$
		- $\operatorname{Var}( T ) = \sum_{i=1}^{n} a_{i}^2 \sigma_{i}^2$
			- **N.B.**: removing the second part because equals 0
		- Fact:
			- $T = \sum_{i=1}^{n} a_{i} X_{i} \sim N\left( \sum_{i=1}^n a_{i}\mu_{i},\ \sum_{i=1}^n a_{i}^2 \sigma_{i}^2 \right)$
			- **N.B.**: linear combinations of normal random variables will have this ^
	- Now suppose $X_{1}\dots X_{n} \overset{\text{iid}}{\sim} N(\mu, \sigma^{2})$
		- What is the distributed of $\overline{X}$?
			- $\overline{X} \sim N\left( \mu, \dfrac{\sigma^{2}}{n} \right)$

#### Standardization of the sample mean $\overline{X}$

- $\overline{X} \sim N\left( \mu, \dfrac{\sigma^{2}}{n} \right)$
- $Z = \dfrac{\overline{X} - \mu}{\sigma / \sqrt{ n }} \sim N(0,1)$
	- recall: mean $=\mu$ and SD = $\sqrt{ \dfrac{\sigma^{2}}{n} } = \dfrac{\sigma}{\sqrt{ n }}$
