### Applying the Central Limit Theorem (CLT)

- Recall CLT:
	- Suppose $X_{1} \dots X_{n}$ are iid random variables from an arbitrary distribution with mean $\mu$ and variance $\sigma^{2} < \infty$
		- **N.B.**: some distributions like the quotient distribution has variance that blows up to infinity so make sure you're dealing with a finite variance
	- Set $\overline{ X } = \dfrac{X_{1} + \cdots + X_{n}}{n}$ as the sample mean.
		- Then $\dfrac{\overline{ X } -\mu}{\sigma /\sqrt{ n }} \overset{ D }{ \to } N(0,1)$ as $n \to \infty$
			- same as $\dfrac{\sqrt{ n }(\overline{ X } -\mu)}{\sigma}$
	- Meaning
		- If $n$ is large enough
			- $\dfrac{\overline{ X }-\mu}{\sigma / \sqrt{ n }} \approx N(0,1)$
			- for $n > 25$, larger the $n$ the better the approximation
			- **N.B.**: will tell us to approximate with CLT on that test
		- multiply $\dfrac{\overline{ X }-\mu}{\sigma / \sqrt{ n }}$ by $\sigma / \sqrt{ n }$
			- $\Rightarrow \left( \overline{ X } - \mu \right) \approx N\left( 0, \frac{\sigma^{2}}{n} \right)$
			- $\overline{ X } \approx N\left( \mu, \frac{\sigma^{2}}{n} \right)$
			- $\frac{\sum_{i=1}^n X_{i}}{n} \approx N\left( \mu, \frac{\sigma^{2}}{n} \right)$
			- $\sum_{i=1}^{n} X_{i} \approx N\left( n \mu, n^{2} \cdot \frac{\sigma^{2}}{n} \right);\ \sum_{i=1}^{n} X_{i} \approx N(n\mu, n \sigma^{2})$
				- all of these ways of writing it are equivalent

- **Example of applying CLT.**
	- Suppose $X_{1} \dots X_{100} \overset{\text{iid}}{\sim} \text{exponential}$ with scale $\theta=2$
		- recall $\mathbb{E}(X) = \theta = 2$
		- and $\operatorname{Var}( X ) = \theta^{2} = 4$
	- Use CLT to approximate:
		1. $P\left( \sum_{i=1}^{100} X_{i} < 202 \right)$
			- $\Rightarrow \sum_{i=1}^{100} X_{i} \sim N(100(2), 100(4))$
			- $\Rightarrow \sum_{i=1}^{100} X_{i} \sim N(200, 400)$
				- $\sigma^{2} = 400$
				- $\sigma = 20$
			- now that it's normal, we have to standardize it (turn it into $Z$)
				- $= P\left( \dfrac{\sum_{i=1}^{100}X_{i} - 200}{20} < \dfrac{202 - 200}{20} \right)$
				- $=P\left( Z < \dfrac{2}{20} \right)$
				- $=P\left(Z < \dfrac{1}{10}\right)$
				- $=P\left( Z < 0.1 \right)$
				- $= \Phi(0.1)$
			- **N.B.**: Don't need to know the distribution you're sampling from, just need to have the mean and the variance to use CLT
		2. $P\left( \overline{ X } < 2.5 \right)$
			- $\overline{ X } \sim N\left( 2, \dfrac{2^2}{100} \right)$
			- $\Rightarrow P\left( \dfrac{\overline{ X } - 2}{\sigma /\sqrt{ n }} < \dfrac{2.5 - 2}{\sigma /\sqrt{ n }} \right) = P\left( Z < \dfrac{0.5}{2 /10} \right)$
				- $=P\left( Z < 0.5(5) \right) = P(Z < 2.5) = \Phi(2.5)$

- **Example.** Suppose it is known that $75\%$ of Math 340 students pass the class. Suppose we take a random sample of 64 of those students.
	- Let $X$ be the random variable that counts the number of the students among the 64 that pass Math 340.
	1. What is the mean of $X$ and $\operatorname{Var}( X )$?
		- Can turn this problem into binomial: $Y_{1} \dots Y_{64} \sim \mathrm{Bern}(P)$ where $P=0.75$, so $X = \sum_{i=1}^{64} Y_{i}$
			- $\Rightarrow X \sim Bin(64, 0.75)$
			- so, $\mu_{\scriptsize X} = np = 64(0.75) = 48$
			- $\Rightarrow \sigma_{\scriptsize X}^2 = np(1-p) = 64(0.75)(0.25) = 12$
	2. Find $P\left( X < 50 \right)$.
		- 64 is a large enough sample to use CLT.
		- what the problem is saying is if we sample 64, what is the probability that less than 50 pass
		- $\Rightarrow X \sim N(48, 12)$
		- Now using CLT...
			- $P(X < 50) = P\left( \dfrac{X-48}{\sqrt{ 12 }} < \dfrac{50-48}{\sqrt{ 12 }} \right)$
				- $=P\left( Z < \dfrac{2}{\sqrt{ 12 }} \right)$
				- $= \Phi\left(\dfrac{2}{\sqrt{ 12 }}\right) = \Phi \left( \dfrac{1}{\sqrt{ 3 }} \right)$
		- why we don't divide by $n$
			- if we say $Y_{1} \dots Y_{n} \overset{\text{iid}}{\sim} \mathrm{Bern}(P)$
			- $\sum_{i=1}^{n} Y_{i} \sim Bin(n, P)$
				- $\mu = nP;\ \sigma^{2} = nP(1-P)$
			- $\overline{ Y } = \dfrac{\sum_{i=1}^{n} Y_{i}}{n};\ \mu_{\scriptsize \bar{Y}} = P,\ \sigma_{\scriptsize \overline{Y}}^2 = \dfrac{P(1-P)}{n}$

## Moment Generating Function of Multivariate Independent Random Variables

- Recall Univariate:
	- By definition the mgf of a random variable $X$ is $M_{\scriptsize X}(t) = \mathbb{E}(e^{tX})$
	- Suppose $X_{1} \dots X_{n}$ are independent rvs.
		- Let $a_{1}, \dots, a_{n}$ be constant and set $Y = \sum_{i=1}^{n} a_{i}X_{i}$
			- **N.B.**: Y is a linear combination of the collection of these random variables
	1. What is the mgf of $Y$?
		- $M_{Y}(t) = \mathbb{E}\left( e^{tY} \right)$
		- $= \mathbb{E}\left( e^{t\left( \sum_{i=1}^{n}a_{i}X_{i} \right)} \right)$
		- $= \mathbb{E}\left( e^{t(a_{1}X_{1} + a_{2}X_{2} + \cdots + a_{n}X_{n})} \right)$
		- $= \mathbb{E}\left( e^{ta_{1}X_{1} + ta_{2}X_{2}+\cdots+ta_{n}X_{n}} \right)$
			- recall that you can write $e^{a+b} = e^{a}\cdot e^{b}$
		- $= \mathbb{E}\left( e^{ta_{1}X_{1}} \cdot e^{ta_{2}X_{2}} \cdot \cdots e^{t a_{n}X_{n}} \right)$
			- all these are functions of independent random variables, so you rewrite them as multiply the moment generating functions
			- $= \mathbb{E}\left( \mu_{1}(X_{1}) \cdot \mu_{2}(X_{2})\cdot \cdots \mu_{n}(X_{n}) \right)$
		- $M_{Y}(t) = \mathbb{E}\left( e^{ta_{1}X_{1}} \right)$
			- think of $ta_{1}$ as a capital $T$, so...
			- $= M_{X_{1}}(a_{1}t)\cdots M_{X_{n}}(a_{n}t)$
- Now do the same for iid...
	- Suppose $X_{1} \dots X_{n}$ are iid
		- when random variables have the same distribution, they have the same mgfs
		- can't have two different random variables with different moment generating functions
			- by definition, mgfs are unique; they uniquely characterize what a random variable is
	1. $M_{X_{1}}(t) = M_{X_{2}}(t) = \cdots = M_{X_{n}}(t)$
	2. Set $Y = \sum_{i=1}^{n} X_{i}$
		- What is MGF of $Y.$
		- $M_{Y}(t) = M_{X_{1}}(t) \cdot \cdots M_{X_{n}}(t).$
			- notice the coefficients are 1 for each t
			- can only write it because they have the same $a_{i}$
			- $= \left( M_{X_{1}}(t) \right)^n$
	3. $\overline{ X } = \dfrac{\sum_{i=1}^{n} X_{i}}{n} = \sum_{i=1}^{n} \frac{1}{n} X_{i}$
		- $M_{\overline{ X }}(t) = \left( M_{X_{1}}\left( \frac{t}{n} \right) \right)^n.$
