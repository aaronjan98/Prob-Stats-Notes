## Exponential Distribution

- Related to Poisson distribution (discrete)
- **Example:** The number of calls Alice receives as a customer service agent is Poisson distributed with rate $\lambda = 15$ calls per hour.
	1. What is the inter arrival times (waiting time between occurrences) random line or fixed.
	2. How long do you expect for her to wait between two calls?
- **Explanation**
	- **N.B.**: Possoin process is the same as Poisson random variable but with time involved
	- Inter arrival time (waiting time before the first call comes in): between 0 and $T_{1}$
		- **N.B.**: [see pic of timeline](https://photos.janovitch.com/share/iNMpF9oSNlg31gmR20d5ecxrcF3ldhKCK3KDMux2irH-LdDj8PEvGrRhebgzv6Vv2ro)
		- examples of inter arrival times
			1. $T_{1} - 0$
			2. $T_{2}-T_{1}$ 
		- The waiting time between arrivals are random variables and they can only be represented with continuous random variables
	1. The random variable $X$ that models the waiting time between occurrences is exponentially distributed.
	2. Expectation of wait time
		- $\lambda = 15$ calls per 1 hr
			- This is the rate of the Poisson
		- $\theta = \frac{1}{\lambda} = \dfrac{1\text{hr}}{15} = 4$ min/calls
			- $\theta$ is called the scaled parameter
			- It's the expectation

- What is the distribution of $X$ the waiting time between occurrence?
	- $\operatorname{CDF}: F_{X}(x) = \mathbb{P}(X \leq x) = 1 - \mathbb{P}(X > x)$.
		- $= 1 - \mathbb{P}(\text{no call on }(0,x))$
		- update $\lambda$
			- $\lambda_{\text{new}} = \lambda x$
		- $= 1- e^{-\lambda x} \dfrac{(\lambda x)^0}{0!}$
		- $= 1- e^{-\lambda x} \quad x \geq 0$
		- $F(X) = \begin{cases} 0 & x < 0 \\ 1 - e^{-\lambda x} & x \geq 0 \end{cases}$
			- is the CDF of exponential withe rate $\lambda$
	- $\operatorname{pdf:}$ of exponential (rate $\lambda$)
		- $f(x) = \left( 1 - e^{-\lambda x} \right)^{\prime}$
		- $f(x) = \lambda e^{-\lambda x} \Rightarrow$ The pdf is
			- $f(x) = \begin{cases} 0 & x \leq 0 \\ \lambda e^{-\lambda x} & x > 0 \end{cases}$
			- **N.B.**: the expectation is measuring average wait-time between calls

- It is common to write the distribution of the exponential random variable using the _scale parameter_ $\theta = \dfrac{1}{\lambda}.$
	- That way it is easy to remember the expected value which is $\theta.$
	- $f(x) = \begin{cases} 0 & x < 0 \\ \dfrac{1}{\theta}e^{-x/\theta} & x > 0 \end{cases}$
	- $F(x) = \begin{cases} 0 & x < 0 \\ 1 - e^{-x/\theta} & x \geq 0 \end{cases}$
	- $\mathbb{E}(X) = \theta,\ \operatorname{Var}( X ) = \theta^{2}$
	
- **Proof.** $\mathbb{E}(X) = \theta$
	- $\mathbb{E}(X) = \int_{0}^\infty x \dfrac{1}{\theta}e^{-x/\theta} dx.$
		- $= \dfrac{1}{\theta} \int_{0}^\infty x e^{-x/\theta}dx.$
		- Proceed by integration by parts
			- Let $dv = e^{-x/\theta} \Rightarrow v = -\theta e^{-x/\theta}$
			- $u = x \Rightarrow du = 1$
		- $= \dfrac{1}{\theta} \left[ -\theta x e^{-x/\theta} \bigg|_{0}^\infty + \int_{0}^\infty \theta e^{-x/\theta}dx \right]$.
		- $= \dfrac{1}{\theta} \left[ 0 + \left( -\theta^{2} e^{-x/\theta}\bigg|_{0}^\infty \right) \right]$
		- $= \dfrac{1}{\theta} \left[ 0 - \theta^{2}\left( \underbrace{ e^{-\infty} }_{ 0 } - 1 \right) \right] = \dfrac{1}{\theta} \cdot \theta^{2} = \boxed{ \theta }$
			- **N.B.**: can also be proved with gamma distribution; variance is a special case of gamma distribution (haven't gotten there yet)

### Exponential Distribution

- **Example:** Customers arrive at a shop accordingly to a Poisson Process with rate $\lambda = 20$ customers per hour.
	- **Question.** What is the probability the shopkeeper waits more than 5 minutes for the first customer to arrive?
	- **Answer.** The wait time until the first customer arrives is an exponential random variable with rate $\lambda = 20 \text{ per 60 min.} \Rightarrow \lambda = \dfrac{20}{60} = \dfrac{1}{3} \text{customers/min.}$ and $\theta = 3 \text{min/customers}$
	- The pdf:
		- $f(x) = \begin{cases} 0 & x \leq 0 \\ \dfrac{1}{3} e^{-x/3} & x > 0 \end{cases}$
	- The CDF:
		- $F(x) = \begin{cases} 0 & x < 0 \\ 1 - e^{-x/3} & x \geq 0 \end{cases}$
	- $P(X \geq 5) = 1 - \mathbb{P}(X \leq 5)$
		- $= 1 - \left( 1 - e^{-5/3} \right)$
		- $= e^{-5/3}$
		- **N.B.**: [see pic of pdf graph](https://photos.janovitch.com/share/q6jVU-1kzf4x_7SmuvBjQvLfC8CpvSvJPrw5k1rwkxyRG4V3L2GkwsdxkMSZPyqVL5I)
	- $\mathbb{P}(X \geq 5) = \int_{5}^\infty \dfrac{1}{3} e^{-x/3} dx.$
		- $= -e^{-x/3}\bigg|_{5}^8$
		- $= -(e^{-\infty} - e^{-5/3})$
		- $= e^{-5/3}$
		- **N.B.**: can use cdf or integration to find probability; both ways are fine

- **Example:** $X$ is an exponential random variable with mean 3.
	- What is the probability that $X$ is less than 4?
	- **N.B.**: need to know either the pdf or cdf, so...
		- pdf: $f(x) = \begin{cases} 0 & x \leq 0 \\ \dfrac{1}{3} e^{-x/3} & x > 0 \end{cases}$
		- CDF: $F(x) = \begin{cases} 0 & x < 0 \\ 1 - e^{-x/3} & x \geq 0 \end{cases}$
	- $\mathbb{P}(X < 4) = 1 - e^{-4/3}.$
		- $= F(4)$.
		- **N.B.**: alternatively, could also do the integration

##### Memoryless Property of Exponential Random Variables

- Suppose $X \sim \operatorname{\text{exponential}}(\underbrace{ \theta }_{ \text{scale} })$
- Consider the event
	- $A = \left\{ x > a \right\};\ a > 0$
	- $B = \left\{ X > a + x \right\}$ for $x > 0$
- See [pic of graph](https://photos.janovitch.com/share/veLtYahDokgb8kYjrAZP4SQj8vIK96dtkCMTl4AM5pXeGa_Hg-C6mIvx3XpXWLS4p0E) of what's really going on
- **Q.** What is $\mathbb{P}(B \big/ A) = \dfrac{\mathbb{P}(\{ X > a + x \} \cap \{ x > a \})}{\mathbb{P}(\{ x > a \})}$
	- $= \dfrac{\mathbb{P}(\{ x > a + x \})}{\mathbb{P}(x > a)}$
	- $= \dfrac{1 - \mathbb{P}(x \leq a + x)}{1 - \mathbb{P}(x < a)}$
	- Recall CDF: $F(x) = \begin{cases} 0 & x < 0 \\ 1 - e^{-x/3} & x \geq 0 \end{cases}$
	- $= \dfrac{e^{- \frac{a+x}{\theta}}}{e^{\frac{-a}{\theta}}} = \dfrac{e^{\frac{-a}{\theta}} \cdot e^{\frac{-x}{\theta}}}{e^{\frac{-a}{\theta}}} = e^{\frac{-x}{\theta}} = \mathbb{P}(X > x)$.
		- **N.B.**: this tells you that if for example a lifetime of a tv or some electronic component is exponentially distributed (eventually going to breakdown) and the component has already live $a$ time, then the probability it will live one more year is not dependent on how long it has lived before; that's why it's called memoryless property of exponential random variables.
			- Its Poisson property that leads to this time independence.
