## Distributions of Bivariate

### Continuous Random Variables

- Recall:
1. $X$ and $Y$ two continuous random variables, then the joint pdf $f(x,y)$ satisfies:
	1. $f(x,y) \geq 0 \quad x,y \in \mathbb{R}.$
	2. $\int_{-\infty}^\infty \int_{-\infty}^\infty f(x,y)dxdy = 1$
		- if we know the support then the integral becomes
		- $\int_{S_{y}}\int_{S_{x}} f(x,y) dxdy = 1$
		- where $S_{x}, S_{y}$ are respectively the supports of $X$ and $Y$.
		2. Joint CDF of $X$ and $Y$:
			- $F(x,y) = P(X \leq x, Y \leq y) = \int_{-\infty}^y \int_{-\infty}^x f(x,y)dxdy$ for all $x,y \in \mathbb{R}$
			- property: $\dfrac{\partial^{2}F(x,y)}{\partial x\partial y} = f(x,y)$
	3. there's also what called the marginal pdf and CDF of $X$ and $Y$ 
		- (a) The marginal pdf of $X$ is
			- $f_{X}(x) = \int_{-\infty}^\infty f(x,y) dy;\ x \in S_{x}$
			- integration with respect to $y$ but after integration only left with effect of $x$ 
			- this is the pdf of its own right
		- (b) marginal CDF of $X$?
			- $F_{X}(x) = P(X \leq x) = \int_{-\infty}^x f_{X}(t)dt$
				- $= \int_{-\infty}^\infty \left( \int_{-\infty}^\infty f(x, y)dy \right) dx$
		- (a') $F_{Y}(y) = \int_{-\infty}^\infty f(x,y)dx \ y \in S_{Y}$
			- $F_{Y}(y)$ is the marginal pdf of $Y$ 
			- $F_{Y}(y) = \int_{-\infty}^y f_{Y}(t)dt = \int_{-\infty}^\infty \int_{-\infty}^\infty f(t_{1},t_{2}) dt_{1} dt_{2}$

#### Independence:

1. $X \perp\!\!\perp Y \Leftrightarrow f(x,y) = f_{X}(x) f_{Y}(y)$ for all $x,y \in \mathbb{R}$
	- if we want to show two random variables $x$ and $y$ are independent, need to show the joint pdf can be written as the marginal pdf of x and marginal pdf of y for $x, y \in \mathbb{R}$
	- **N.B.**: $\perp\!\!\perp$ means ‘independence’ and $\Leftrightarrow$ means ‘if and only if’
2. $X \perp\!\!\perp Y \Leftrightarrow F(x,y) = F_{X}(x) F_{Y}(y)$ for all $x,y \in \mathbb{R}$
	- **N.B.**: [see pic](https://photos.janovitch.com/share/V8dOJhubh7OkB-MBxuGrVefH_orFzbqMffDYqiSx1nWhFL7EvTfwQVeOtc9Fa2KD8Bw)

- **Example.** $X$ and $Y$ are two continuous random variables with joint pdf
	- $f(x,y) = x + y; \ 0 < x < 1,\ 0 < y < 1$ and 0 elsewhere
		- our support is $S_{X} = (0,1)$ and $S_{Y} = (0,1)$
	1. Find $P\left( X \leq \frac{1}{2}, Y \leq \frac{1}{3} \right)$
		- Wrong: $=\int_{0}^1 \int_{0}^1 (x+y) dx dy$
			- the event has to be less than $\frac{1}{2}$ and $y \leq \frac{1}{3}$
			- need to take this constraint into account
		- Correct: $\int_{0}^{1/3} \int_{0}^{1/2} (x+y)\ dx\,dy$
			- $= \int_{0}^{1/3} \left[ \frac{x^2}{2} + yx \bigg|_{0}^{1/2} \right]dy$
			- $=\int_{0}^{1/3} \left[ \dfrac{\left( 1/2 \right)^2}{2} + y \cdot \frac{1}{2} - 0 \right] dy.$
			- $= \int_{0}^{1/3} \frac{1}{8} + \frac{y}{2} dy.$
			- $= \dfrac{1}{8}y + \dfrac{y^2}{4}\bigg|_{0}^{1/3}$
			- $= \dfrac{1}{8} \dfrac{1}{3} + \dfrac{(1 / 3)^2}{4} - 0$
			- $= \dfrac{1}{24} + \dfrac{1}{9(4)}$
			- $= \dfrac{1}{24} + \dfrac{1}{36} = \dfrac{24+36}{24(36)} = \dfrac{5}{72}$
	2. Find $P\left( X < \frac{1}{2} \right)$
		- have to use marginal pdf as y is not involved
		- it's the same as $P\left( X < \frac{1}{2}, 0 < Y < 1 \right)$
			- if there's no constraint on Y, then it has to be everything on the support
		- $\Rightarrow \int_{0}^1 \int_{0}^{1/2} (x+y) \ dx\,dy$
			- $= \int_{0}^1 \left[ \frac{x^2}{2} + yx\bigg|_{0}^{1/2} \right]dy$
			- $= \int_{0}^1 \left( \frac{1}{8} + \frac{y}{2} \right)dy$
			- $= \frac{1}{8}y + \frac{y^2}{4}\bigg|_{0}^1 = \frac{1}{8}(1) + \frac{1}{4} - 0 = \frac{1}{8} + \frac{2}{4+2} = \boxed{ \frac{3}{8} } = P\left( X < \frac{1}{2} \right)$
	3. Find the marginal pdf of $X$
		- Recall general formula for pdf of $X$ 
			- need to integrate joint pdf and taking effect of $y$ out
			- $f_{X} (x) = \int_{-\infty}^\infty f(x,y)dy; \quad x \in S_{X} = (0,1)$
				- always mention the suppoort because $x \in (0,1)$
			- but need to bring it to the support
		- $\Rightarrow \int_{0}^1 (x+y)dy$
			- implicit differentiation
			- $= xy + \frac{y^2}{2} \bigg|_{0}^1$
			- $= x(1) + \frac{1^2}{2} = x + \frac{1}{2} \quad x \in (0,1)$
		- this is how you should write the marginal of $x$ 
			- $f_{X}(x) = \begin{cases} x + \frac{1}{2} & 0 < x < 1 \\ 0 & \mathrm{elsewhere} \end{cases}$
				- marginal pdf is instructed from the joint pdf but it still adds up to 1
	4. Use the marginal pdf to find $P\left( X < \frac{1}{2} \right)$
		- $P\left( X < \frac{1}{2} \right) = \int_{0}^{1/2} X + \frac{1}{2} DX$
			- $= \frac{x^2}{2} + \frac{1}{2}x \bigg|_{0}^{1/2}$
			- $= \dfrac{\left( \frac{1}{2} \right)^2}{2} + \frac{1}{2} \cdot \frac{1}{2} - 0 = \frac{1}{8} + \frac{1}{4} = \frac{3}{8}$
		- use marginals over joint if possible to avoid double integrals

#### Expectations:

- Suppose $X$ and $Y$ are two random variables with joint pdf $f(x,y)$
	- Let $\mu(X,Y)$ be a function of $(X,Y)$
	- Then $\mathbb{E}(\mu(X,Y)) = \int_{-\infty}^\infty \int_{-\infty}^\infty \mu(x,y)f(x,y)\ dx\,dy$
		- if you know the support, than change them to their respective support
