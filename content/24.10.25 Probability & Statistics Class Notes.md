### Memoryless Property (No aging) of Exponential Distribution

- Recall if $X \sim \operatorname{\text{exponential}}(\text{rate }x> 0)$
- Then for $a > 0; \ x > 0$
- $\mathbb{P}(X > a+x \big/ X > a) = \mathbb{P}(X > x).$

- **Example:** The life time $X$ of an electronic component is exponentially distributed with mean-life 500 hours.
	- **N.B.**: scale = $\dfrac{1}{\lambda}$
	1. What is pdf of $X$? CDF of $X$?
		- $f(x) = \begin{cases} 0 & x \leq 0 \\ 500 e^{-x/500} & x > 0 \end{cases}$
		- $P(X\leq x) = F(X) = \begin{cases} 0 & x < 0 \\ 1 - e^{-x/500} & x \geq 0 \end{cases}$
	2. What is the probability the electronic component live past 600 hours.
		- $\mathbb{P}(X \geq 600) = e^{-600/500} = e^{-6/5}$
	3. Given the electronic component has already lived 300 hours, what is the probability it will live past 900 hours?
		- $\mathbb{P}(X \geq 900 \big/ X \geq 300) = \mathbb{P}(X \geq \underbrace{ 600 }_{ x } + \underbrace{ 300 }_{ a } \big/ X \geq \underbrace{ 300 }_{ a })$
		- $= \mathbb{P}(X \geq 600) = e^{-6/5}$
		- **N.B.**: there's some chemicals that don't have decay and so it's modeled by a exponential distribution

## Gamma Distribution

- **N.B.**: exponential distribution is a specific case of the Gamma Distribution
	- other examples include Chi-square distribution
	- used to model lifetime (even people because it's left skewed)

1. Gamma Function $\Gamma(x)$
	- $\Gamma(\alpha) = \int_{0}^\infty x^{\alpha - 1} \cdot e^{-x} dx;\ \alpha > 0$
		- **N.B.**: this function is always positive
2. Facts about $\Gamma(\alpha)$
	- (a) $\Gamma(1) = 1$
		- $\Gamma(1) = \int_{0}^{\infty} x^{1-1} e^{-x} dx = \int_{0}^{\infty} e^{-x} dx = - e^{-x} \bigg|_{0}^\infty = -(e^{-\infty} - e^{-0}) = \boxed{ 1 }.$
			- **N.B.**: $e^{-x}$ is the pdf of exponential with rate of 1 so integration of entire support is 1
	- (b) $\Gamma(\alpha) = (\alpha - 1)\Gamma(\alpha - 1)$
		- By definition $\Gamma(\alpha) = \int_{0}^\infty x^{\alpha-1} \cdot e^{-x}dx ;\ \alpha > 0$
			- Set $u = x^{\alpha - 1} \Rightarrow du = (\alpha - 1) x^{\alpha - 2}dx.$
				- $dv = e^{-x}dx \Rightarrow v = -e^{-x}$
			- $\Gamma(\alpha) = \underbrace{ -x^{\alpha-1} e^{-x}\bigg|_{0}^\infty }_{ 0 } - \int_{0}^\infty - (\alpha-1)x^{\alpha-2}e^{-x dx.}$
			- $\Gamma(\alpha) = (\alpha - ) \int_{0}^\infty x^{\alpha - 2} \cdot e^{-x}dx = (\alpha - 1) \int_{0}^\infty x^{\alpha-1}e^{-x}dx$
				- **N.B.**: $\int_{0}^\infty x^{\alpha - 2} \cdot e^{-x}dx$ is $\Gamma(\alpha) = -1$
			- $= \boxed{ (\alpha - 1)\Gamma(\alpha-1) }$
	- (c) $\Gamma(n) = (n-1)!$ for $n$ positive integers $\{ 1, 2, 3, 4, 5,\dots \}$
		- $\Gamma(n) = (n-1)\Gamma(n-1)$. with $n$ positive integer.
			- rewrite $\Gamma(n-1)$
				- $\Gamma(n-1) = (n-2)\Gamma(n-2)$
			- $\Gamma(n) = (n-1)(n-2)\Gamma(n-2)$
				- $\Gamma(n-2) = (n-3)\Gamma(n-3)$
			- $\Gamma(n) = (n-1)(n-2)(n-3)\Gamma(n-3)$
			- $\vdots$
			- $\Gamma(n) = (n-1)(n-2)(n-3)\cdots 2 \cdot 1 \cdot \underbrace{ \Gamma(1) }_{ 1 } = \boxed{ (n-1)! }$

- **Definition:** A continuous random variable is said to be Gamma distributed with shape $\alpha > 0$ and scale $\theta > 0$ if its pdf is given by
	- **N.B.**: shape and scale are the two parameters of Gamma distributions (both positive)
	- $f(x) = \begin{cases} 0 & x \leq 0 \\ \dfrac{1}{\Gamma(\alpha)\cdot \theta^{\alpha}} \cdot x^{\alpha - 1}\cdot e^{-x/\theta} & x > 0 \end{cases}$
	- We write $X \sim \Gamma(\alpha, \theta)$
		- or $X \sim \operatorname{\Gamma}(\alpha, \theta)$ where $\alpha$ is the shape parameter and $\theta$ is the scale parameter
	- graphed as skewed distributions
		- **N.B.**: [pic available](https://photos.janovitch.com/share/U-SqEJFrGiwCLBu-MVJbJO_9ckaJ2n4B50q5VLReNtQwpaJpIYCrZQBAijToRdI21VE)
	- check if pdf adds up to 1; is $f(x)$ a pdf? Well:
		- $\int_{0}^\infty f(x) dx = \int_{0}^\infty \dfrac{1}{\Gamma(\alpha)\theta^{\alpha}} \cdot x^{\alpha - 1} \cdot e^{-x/\theta}dx = \dfrac{1}{\Gamma(\alpha) \cdot \theta^{\alpha}}\int_{0}^\infty x^{\alpha-1}e^{-x/\theta}dx$
			- do change of variables for $\int_{0}^\infty x^{\alpha-1}e^{-x/\theta}dx$
				- $I = \int_{0}^\infty x^{\alpha - 1} \cdot e^{-x/\theta}dx$
					- set $y = \frac{x}{\theta}; dy = \frac{1}{\theta}dx \Rightarrow dx = \theta dy$
						- replace $y=\frac{x}{\theta}$ with $x = \theta y$
				- $I = \int_{0}^\infty \theta^{\alpha-1}y^{\alpha-1}e^{-y}\theta^{1}dy = \theta^\alpha \int_{0}^\infty y^{\alpha -1} e^{-y}dy = \theta^{\alpha}\Gamma(\alpha)$
			- multiply $I$ with result we got previously
				- $\dfrac{1}{\Gamma(\alpha)\cdot\theta^\alpha} \cdot \theta^{\alpha}\Gamma(\alpha) = \boxed{ 1 }.$

- **Proposition:** Suppose $X \sim \operatorname{Gamma}(\alpha, \theta)$
	- Then the mgf of $X$ is
		- $M_{X}(t) = \dfrac{1}{(1-\theta t)^{\alpha}}; \quad \theta < \dfrac{1}{t}.$
	- Recall the general mgf, by definition: $M_{X}(t) = \mathbb{E}(e^{tX})$
		- $= \int_{0}^{\infty} e^{tX} \dfrac{1}{\Gamma(\alpha)\theta^{\alpha}} \cdot x^{\alpha-1} \cdot e^{-x/\theta} dx.$
		- $= \dfrac{1}{\Gamma(\alpha)\theta^\alpha} \int_{0}^{\infty} x^{\alpha-1} e^{tx} e^{-x/\theta} dx$
		- $= \dfrac{1}{\Gamma(\alpha)\theta^\alpha} \cdot \underbrace{ \int_{0}^\infty x^{\alpha -1} e^{-\left( \frac{1-\theta t}{\theta} \right)x}dx. }_{ I }$
		- Do u-sub
			- set $y = \dfrac{1-\theta t}{\theta} x \Rightarrow x = \dfrac{\theta y}{1-\theta t}$
			- $dy = \dfrac{1 - \theta t}{\theta} dx \Rightarrow dx = \dfrac{\theta}{1-\theta t} dy.$
			- $I = \int_{0}^\infty \dfrac{\theta^{\alpha-1}}{(1-\theta t)^{\alpha-1}}y^{\alpha-1}e^{-y} \dfrac{\theta}{1-\theta}dy = \int_{0}^\infty \dfrac{\theta^\alpha}{(1-\theta t)^\alpha}y^{\alpha - 1} e^{-y} dy$
				- $= \dfrac{\theta^{\alpha}}{(1-\theta t)^{\alpha}} \int_{0}^\infty y^{\alpha - 1}e^{-y} dy$
				- $= \dfrac{\theta^{\alpha}}{(1-\theta t)^\alpha}\Gamma(\alpha)$
		- $M_{X}(t) = \dfrac{1}{\Gamma(\alpha)\theta^\alpha} \dfrac{\theta^{\alpha}\Gamma(\alpha)}{(1-\theta t)^{\alpha}}$
		- $\boxed{ M_{X}(t) = \dfrac{1}{(1-\theta t)^{\alpha}} }$
- $\mathbb{E}(X) \text{ and } \operatorname{Var}( X )$
	- $X \sim \operatorname{Gamma}(\alpha, \theta)$
	- $M_{X}(t) = (1-\theta t)^{-\alpha}$
		- **N.B.**: better to write it this way
	- $M_{X}'(t) = -\alpha (1-\theta t)^{-\alpha - 1} (-\theta)$
		- **N.B.**: have to use chain rule
	- $M_{X}'(0) = -\alpha (1- 0 \cdot \theta)^{-\alpha - 1} (-\theta) = \alpha \theta.$
		- $\boxed{ \mathbb{E}(X) = \alpha \theta }$
	- $M_{X}''(t) = \alpha\theta (-\alpha -1)(1-\theta t)^{-\alpha -2}(-\theta)$
	- $M_{X}''(0) = \alpha \theta (-\alpha-1)(1-0)^{-\alpha - 2}(-\theta) = \alpha \theta^{2}(\alpha+1) = \alpha^{2}\theta^{2} = \mathbb{E}(X^2)$
	- $\operatorname{Var}( X ) = \mathbb{E}(X^2) - \left( \mathbb{E}(X) \right)^2 = \alpha^{2}\theta^{2} + \alpha\theta^{2} - (\alpha\theta)^2 = \alpha \theta^{2}$
	- $\boxed{ \operatorname{Var}( X ) = \alpha \theta^{2} }$
