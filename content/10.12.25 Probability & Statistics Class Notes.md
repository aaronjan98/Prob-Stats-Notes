## Sample Linear Regression

- how is SAT (math score) related to your Calculus test?
	- if you score high SAT, you can expect a high grade in Calculus in college for example.
	- want to find a functional relationship between these metrics
- Plot SAT score on a graph with $x$ representing the SAT score and $y$ representing the Calculus score.
	- **N.B.**: [see pic of graph](https://photos.janovitch.com/share/cfjaUHHulEBl1RoLs8xmjvKQlauEghT70WmMPf_kzVbozGID2VT06DwUIYfTX0GYrR4)
	- fit a line in the trend of the graph
		- $y = \alpha + \beta x$
	- but we don't know what $\alpha$ or $\beta$ is
- based on the SAT score, how do we predict what the Calculus score is going to be?
	- draw a line that best fits the spread of the data
	- the regression line is the one that fits the points the best possible
- the regression line has the error term when the predicted value doesn't match the actual value.
	- to create the line: compute the square errors and minimize the errors
	- take the spread of the data to be
		- $(x_{1}, y_{1})$
		- $\vdots$
		- $(x_{n}, y_{n})$
	- for the point $i$, $(x_{i}, y_{i})$
		- the predicted value, $\hat{y_{i}} = \alpha + \beta x_{i}$
	- total (squared )error is modeled with the objective function:
		- $E(\alpha, \beta) = \sum_{i=1}^n \left( y_{i} - \hat{y}_{i} \right)^2$
			- where $y_{i}$ is the actual value and $\hat{y}_{i}$ is the predicted value
		- $= \sum_{i=1}^{n} (y_{i} - (\alpha + \beta x_{i}))^2$
			- need to square the errors to minimize the function (to get errors cancel each other out)
		- $= \sum_{i=1}^{n} (y_{i} - \alpha - \beta x_{i})^2$
			- want to find $\alpha$ and $\beta$ that minimize this function
				- want to make the function as small as possible
		- minimize the function by taking derivative and critical points
			- this function is already convex (when you find $\alpha$ and $\beta$, they are automatically the minimum values)
	- OLS (ordinary least square Method)
		- the method where you minimize using the objective function and take derivative to find $\alpha$ and $\beta$
		- $\dfrac{\partial E}{\partial \alpha} = 2 \left( \sum_{i=1}^{n} (y_{i} - \alpha - \beta x_{i})(-1) \right) = 0$
			- $\Rightarrow \sum_{i=1}^{n} y_{i} - n\alpha - \beta \sum_{i=1}^{n} x_{i} = 0 \qquad\quad \dagger$
		- $\dfrac{\partial E}{\partial \beta} = 2\left( \sum_{i=1}^{n} (y_{i} - \alpha - \beta x_{i})(-x_{i}) \right) = 0 \qquad \ddagger$
			- $\Rightarrow \sum_{i=1}^{n} x_{i}y_{i} - \alpha \sum_{i=1}^{n} x_{i} - \beta \sum_{i=1}^{n} x_{i}^2 = 0$
		- solve for $\alpha$ in one equation and plug into the other
			- from first equation ($\dagger$), we have $\hat{\alpha} = n \bar{Y} - \beta \bar{X}$ where $\bar{Y} = \dfrac{\sum_{i=1}^{n}Y_{i}}{n}$ and $\bar{X} = \dfrac{\sum_{i=1}^{n}X_{i}}{n}$
			- $\sum_{i=1}^{n} y_{i} - \beta \sum_{i=1}^{n} X_{i} = n\alpha$
			- $\dfrac{\sum_{i=1}^{n} Y_{i}}{n} = \beta \dfrac{\sum_{i=1}^{n}X_{i}}{n} = \alpha$
				- $\bar{Y} - \beta \bar{X} = \alpha$
		- now solve using second equation ($\ddagger$)
			- $\sum_{i=1}^{n} x_{i} y_{i} - \left( \bar{Y} - \beta \bar{X} \right) n\bar{X} - \beta \sum_{i=1}^{n} x_{i}^2 = 0$
			- $\sum_{i=1}^{n} x_{i}y_{i} - n \bar{X} \bar{Y} + \beta n \bar{X}^2 - \beta \sum_{i=1}^{n} x_{i}^2 = 0$
			- $\sum_{i=1}^{n} x_{i}y_{i} - n \bar{X} \bar{Y} + \beta \left( n \bar{X}^2 - \sum_{i=1}^{n}x_{i}^2 \right) = 0$
			- $\boxed{ \hat{\beta} = \dfrac{\sum_{i=1}^{n}x_{i}y_{i} - n \bar{X} \bar{Y}}{\sum_{i=1}^{n}x_{i}^2 - n \bar{X}^2} } = \dfrac{\sum_{i=1}^{n}(x_{i}-\bar{X})(y_{i}-\bar{Y})}{\sum_{i=1}^{n}(x_{i} - \bar{X})^2}$
				- similar to how $\operatorname{Var}( X ) = \mathbb{E}\left[ (x - \mu)^2 \right]$ can be solved to show $\mathbb{E}(X^2) - (\mu)^2$
				- **N.B.**: this is the sample covariance
			- If we have the data, then from $\beta$ we can compute $\alpha$
				- so, $\boxed{ \hat{\alpha} = \bar{Y} - \hat{\beta} \bar{X} }$
				- this will give you the best fitting line

- Set $\mathcal{S}_{x x} = \sum_{i=1}^{n} (X_{i} - \bar{x})^2$ and $\mathcal{S}_{x y} = \sum_{i=1}^{n} (x_{i} - \bar{x})(y_{i}-\bar{y})$
- **N.B.**: rewrite with the coefficient of $\bar{x}$
	- $\hat{\beta} = \dfrac{\mathcal{S}_{xy}}{\mathcal{S}_{xx}} \quad \dagger\!\!\dagger$

- Sample Covariance
	- Sample Covariance between $X$ and $Y$
	- $\mathcal{S}_{x y}^c = \dfrac{1}{n-1} \quad \sum_{i=1}^{n} (x_{i} - \bar{x})(y_{i}-\bar{y})$
		- small $c$ for covariance
		- same as covariance formula: $\operatorname{Cov}(X, Y) = \mathbb{E}(X - \mathbb{E}(X))(Y - \mathbb{E}(Y))$
			- but we don't have expectation of X or Y, but we have $\bar{X}$ and $\bar{Y}$
			- in fact, if the sample is large enough, it should converge to the covariance
	- Sample Variance of $X$
		- $\mathcal{S}_{x_{x}}^c = \dfrac{1}{n-1} \quad \sum_{i=1}^{N} (x_{i} - \bar{x})^2$
	- Sample Variance of $Y$
		- $\mathcal{S}_{y_{y}}^c = \dfrac{1}{n-1} \sum (y_{i} - \bar{y})^2$

- The sample correlation coefficient
	- We don't have
		- $f_{(x,y)} = \dfrac{\operatorname{Cov}(X, Y)}{\sqrt{ \operatorname{Var}( X ) }\sqrt{ \operatorname{Var}( Y ) }}$
	- so it would be
		- $r = \dfrac{\sum (x_{i} - \bar{x})(y_{i} - \bar{y})}{\sqrt{ \mathcal{S}_{x x} }\sqrt{ \mathcal{S}_{y y} }} = \dfrac{\mathcal{S}_{x y}}{\sqrt{ \mathcal{S}_{x x} }\sqrt{ \mathcal{S}_{y y} }}$
	- write $\beta$ but include $r$ in the expression
		- $\hat{\beta} = \dfrac{\mathcal{S}_{x y}}{\sqrt{ \mathcal{S}_{x x} }\sqrt{ \mathcal{S}_{y y} }} \cdot \dfrac{\sqrt{ \mathcal{S}_{y y} }}{\sqrt{ \mathcal{S}_{x x} }}$
			- so $\dfrac{\mathcal{S}_{x y}}{\sqrt{ \mathcal{S}_{x x} }\sqrt{ \mathcal{S}_{y y} }} = r$
			- then $\boxed{ \hat{\beta} = r \cdot \dfrac{\sqrt{ \mathcal{S}_{y y} }}{\sqrt{ \mathcal{S}_{x x} }} }$
				- this quantity, $\dfrac{\sqrt{ \mathcal{S}_{y y} }}{\sqrt{ \mathcal{S}_{x x} }}$ is always positive
				- $r$ is the correlation between $x$ and $y$ (or else it would be $0$)
				- if $r$ is negative, then they're moving in the opposite directions (higher SAT score, the lower the calculus score)
				- likewise for when $r$ is positive
				- if $\lvert r \rvert = 1$, then there's no errors, perfect correlation
				- note that $\lvert r \rvert \leq 1$ must always be true
	- rewrite ($\dagger\!\dagger$) using $\mathcal{S}$
		- $\hat{\beta} = \dfrac{\mathcal{S}_{xy}}{\mathcal{S}_{xx}}$

- **Sum Square Residuals** (or Error)
	- $SSE = \sum_{i=1}^{n} (y_{i} - \hat{y}_{i})^2$
		- you want the sum to be small (but how small is small?)
		- small is relative, depends on what random variables we're dealing with
	- $= \sum_{i=1}^{n} (y_{i} - \hat{\alpha} - \hat{\beta} x_{i})^2$
		- $\hat{y}_{i} = \hat{\alpha} + \hat{\beta} x_{i}$ is the prediction
		- can also plug in $\alpha$ and $\beta$ and play around with it
	- usually use computers to do this regression stuff

- Use data from Midterm to predict the Finals with $y = \alpha + \beta x$ [^2]
	- the test scores are also on page 283 of the textbook
- plug midterm results in `R`: [^1]
	```R
	x = c(70, 74, 80, 84, 80, 67, 70, 64, 74, 82)
	y = c(87, 79, 88, 98, 96, 73, 83, 79, 91, 94)
	print(lm(y~x))
	summary(lm(y~x))
	```
	- the intercept is `11.13` and the $x$ coefficients are $\alpha = 11.132$ and $\beta = 1.016$
		- If your midterm score increased by $1$, then the final increases by $11$ because $\hat{\alpha} = \text{intercept}$ from $y = \alpha + \beta x$
			- and $\hat{\beta} = 1$ means they're positively correlated.
	- **N.B.**: `lm` stands for linear model
	- from the `R` results, p value tells you if `1` is significant
